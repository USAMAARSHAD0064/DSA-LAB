# DSA Lab 06 – Singly Linked List

Singly linked list operations and applications in C++.

## Files

- `Q01_Create_And_Display.cpp` – Create And Display
- `Q02_Linked_List_ADT.cpp` – Linked List ADT
- `Q03_Position_Menu.cpp` – Position Menu
- `Q04_Hospital_Patient_Queue.cpp` – Hospital Patient Queue
- `Q05_Library_Reservation_Queue.cpp` – Library Reservation Queue

## Build and Run

```bash
g++ -std=c++17 Q01_*.cpp -o program
./program
```

Each `.cpp` file is a standalone program with its own `main()`.
