# DSA Lab 03 – Generic Data Structures

Template-based generic list data structures in C++.

## Files

- `Q01_Abstract_List.cpp` – Abstract List
- `Q02_MyList_Menu.cpp` – MyList Menu
- `Q03_CustomList_Menu.cpp` – CustomList Menu

## Build and Run

```bash
g++ -std=c++17 Q01_*.cpp -o program
./program
```

Each `.cpp` file is a standalone program with its own `main()`.
