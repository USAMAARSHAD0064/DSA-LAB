# DSA Lab 02 – C++ Abstract Classes

Abstract classes and pure virtual functions in C++.

## Files

- `Q01_Shape_Area.cpp` – Shape Area
- `Q02_Employee_Salary.cpp` – Employee Salary
- `Q03_Library_System.cpp` – Library System

## Build and Run

```bash
g++ -std=c++17 Q01_*.cpp -o program
./program
```

Each `.cpp` file is a standalone program with its own `main()`.
