# DSA Lab 05 – Queue

Queue ADT and queue-based applications in C++.

## Files

- `Q01_Queue_ADT_Menu.cpp` – Queue ADT Menu
- `Q02_Queue_Using_Two_Stacks.cpp` – Queue Using Two Stacks
- `Q03_Reverse_First_K.cpp` – Reverse First K
- `Q04_Support_Ticket_System.cpp` – Support Ticket System
- `Q05_Document_Print_Queue.cpp` – Document Print Queue
- `Q06_Package_Delivery_System.cpp` – Package Delivery System

## Build and Run

```bash
g++ -std=c++17 Q01_*.cpp -o program
./program
```

Each `.cpp` file is a standalone program with its own `main()`.
