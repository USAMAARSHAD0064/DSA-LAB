# DSA Lab 04 – Stack

Stack ADT and stack-based applications in C++.

## Files

- `Q01_Stack_ADT_Menu.cpp` – Stack ADT Menu
- `Q02_Min_Stack.cpp` – Min Stack
- `Q03_Parking_Lot.cpp` – Parking Lot
- `Q04_Text_Editor_Undo_Redo.cpp` – Text Editor Undo Redo

## Build and Run

```bash
g++ -std=c++17 Q01_*.cpp -o program
./program
```

Each `.cpp` file is a standalone program with its own `main()`.
