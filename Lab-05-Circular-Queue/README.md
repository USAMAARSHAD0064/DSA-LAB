# DSA Lab 05 – Circular Queue

Circular queue implementations and applications in C++.

## Files

- `Q01_Bank_Customer_Queue.cpp` – Bank Customer Queue
- `Q02_Cinema_Ticket_Booking.cpp` – Cinema Ticket Booking
- `Q03_Printer_Job_Queue.cpp` – Printer Job Queue

## Build and Run

```bash
g++ -std=c++17 Q01_*.cpp -o program
./program
```

Each `.cpp` file is a standalone program with its own `main()`.
